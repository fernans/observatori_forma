# Observatori Forma

Archival visual documentation for *Observatori de la Forma*: 45 JPEG panels covering the concept, graphic image, target audience, spatial design, plans and thematic development of an interactive 3D presentation, plus the original ZIP bundle. This repository intentionally publishes only these documentation assets.

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

For security reasons, some parts of the project may have been edited or removed.

## Requirements / How to run

No build step or source toolchain is required for the material in this repository. Open `docs/OBSERVATORI JPG/*.jpg` with any standard JPEG viewer; `docs/OBSERVATORI JPG.zip` contains the same 45 images in compressed form. The original interactive piece used the Shiva 3D client (version 2.1.5.7 in the excluded runtime copy) on Windows, but no player is needed to view the documentation images.

## Excluded material

The nested `forma/` directory is ignored on purpose: it is a reference copy of the separate `forma` project listed in the batch publication plan. Legitimate third-party `refs/` / `ref/` content is not blanket-ignored; none was present here.
